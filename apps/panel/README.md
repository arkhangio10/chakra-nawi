# apps/panel/ · Panel del técnico

Una sola página: casos por prioridad (urgente → técnico → amarillo → verde), foto con cajas, reglas aplicadas con su fuente y tipo, botón "llamar a Noor".
Responsable: P3. Consume `GET /casos` (lista de `caso.schema.json`) y `rules.schema.json` para mostrar fuente y tipo. Sin mapas ni gráficos.
